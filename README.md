# AURAFX Automotive Studio

**Premium, multi-page, cinematic website + immersive 3D showroom**  
Built for a real-world car wrapping, detailing, and customisation studio based in **Rohini, Delhi, India**.

---

## 🗂 Project Structure

```
website3again2/
├── index.html        ← Home (Apple-style cinematic scroll)
├── index.css         ← Home page specific styles
├── services.html     ← 13 services with category filter
├── portfolio.html    ← Before/after sliders + lightbox gallery
├── about.html        ← Brand story, timeline, team
├── contact.html      ← Booking form + WhatsApp + map
├── showroom.html     ← Three.js 3D immersive showroom
├── style.css         ← Shared design system
└── script.js         ← Scroll reveal, nav, filters, animations
```

---

## ✨ Features

### Website Layer
- Cinematic scroll storytelling (Apple Vision Pro aesthetic)
- CSS car silhouette hero with particle system & glow
- Animated stat counters, before/after demo, testimonials
- 13 automotive services across 4 categories
- Portfolio with draggable before/after sliders + fullscreen lightbox
- Brand story with 6-year experience timeline
- Premium contact form with WhatsApp integration
- Fully responsive (mobile + desktop)

### 3D Showroom (Three.js)
- Detailed SUV-style 3D car model (Creta/Seltos proportions)
- Orbit controls — drag to rotate, scroll to zoom
- 6 real-time material finish switchers:
  - Original Paint · Matte Black · Gloss Red
  - Satin Green · Chrome Silver · Colour Shift
- Floating HUD panels (Services, Finish, CTA)
- Particle system, cinematic fog, reflective floor
- Overhead spotlight + dual rim lights (blue + warm white)
- Animated platform ring glow
